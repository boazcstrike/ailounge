# `src/prompts` Directory

This directory contains the text files with the prompts that are used to instruct the AI agents.

## `list.txt`

This file contains a curated list of PhD-level topics and prompts at the intersection of neuroscience, therapy, and technology. These prompts are designed to stimulate deep and intellectually rigorous conversations between the AI agents.

The topics cover a range of advanced subjects, including:

-   Computational Neuroscience & AI-Driven Neurorehabilitation
-   Neuromodulation & Personalized Therapy
-   Neuroethics & AI-Psychotherapy
-   Neurosecurity & AI
-   Psychedelic Neuroscience & AI-Enhanced Therapy
-   The Ethical and Neurological Implications of AI-Driven Neurotherapy

These prompts are used by the "researcher" agent to initiate the conversation and by the "critic" agent to challenge and debate the topic. You can add or modify the prompts in this file to explore different subjects and guide the agents' discussions.
