# `src` Directory

This directory contains the core source code for the AI Lounge application.

## Files

-   **`agentsteam.py`**: The main entry point for the application. This script orchestrates the team of AI agents to answer a user's question.

-   **`agentsreader.py`**: This file is responsible for reading and parsing the agent configurations. It defines the roles, prompts, and models used by each agent.

-   **`argue.py`**: This module manages the debate between the "researcher" and "critic" agents.

-   **`argue_tts.py`**: This script adds text-to-speech (TTS) functionality to the application, allowing the final answer to be read aloud.

-   **`consciousness.py`**: This file likely contains experimental code related to agent consciousness or self-awareness.

-   **`test.py`**: A file for testing purposes.

## Directories

-   **`constants/`**: This directory contains the constant variables that are used throughout the application.

-   **`prompts/`**: This directory contains the text files with the prompts that are used to instruct the AI agents.

-   **`utils/`**: This directory contains various utility functions that are used by the other scripts in the application.
