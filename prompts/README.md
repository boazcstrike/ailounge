# Image Generation Prompts and Resources

This directory contains a collection of resources for generating images with Stable Diffusion, including recommended models, LoRAs, prompts, and settings.

## Models

-   **`sd-models.md`**: A detailed list of Stable Diffusion models with links to [Civitai](https://civitai.com) and recommended settings for each model, including samplers, steps, CFG scale, resolution, and high-resolution fix settings.

-   **`2-8-2025.md`**: Contains recommended settings for various realistic and cartoon-style Stable Diffusion models, such as `Juggernaut XL` and `CyberRealistic XL`.

## LoRAs

-   **`loras.md`**: A list of LoRA (Low-Rank Adaptation) models for Stable Diffusion, with links to [Civitai](https://civitai.com), recommended weights, and trigger words. It includes LoRAs for enhancing details, adjusting weight, and specific hairstyles.

## Prompts

-   **`img-prompts.txt`**: A large collection of prompts for generating images in various styles, including traditional painting, steampunk, sketchbook, and anime. It also includes prompts for scenery and pictures of women.

-   **`animals.md`**: Contains prompts for generating wildlife photos.

-   **`selfies.md`**: Provides prompts for generating selfies.

-   **`selfdoc.md`**: A comprehensive guide to keywords and prompts for image generation, categorized into quality, photography, lens, lighting, colors, style, artists, and detailed negative prompts for people.

## Embeddings

-   **`embeddings.md`**: Lists embeddings, likely for use in negative prompts to improve details in generated images.

## Instructions

-   **`sd-diff-comfyui-mac-instruction.txt`**: Contains a command-line instruction for running a Python script related to Stable Diffusion on a Mac with ComfyUI.
